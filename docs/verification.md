## 体积与隔离

- 仅笔示例约 20 KB；没有 ASR 类、语音模型、原生推理库或 RECORD_AUDIO 权限。
- 仅 ASR 示例约 217 MiB；没有笔模块类。
- 组合示例约 217 MiB；由宿主同时引入两个模块。
- 复用库本身很小：ASR Android AAR 约 14 KB、笔 AAR 约 4 KB。模型和官方运行库单独提供，不能把这些小 AAR 大小说成完整语音功能的安装体积。

## 合成语音结果

模型初始化约 2.37 秒。五个单句样本的第一份有效初稿出现在已输入 416–1056 毫秒音频后；整句复核纯计算约 66–127 毫秒。这里不包含真实麦克风采集、等待停顿和队列等待，不能作为端到端用户延迟承诺。

- 中文提醒句：数字规范化为 `3`，内容正确。
- 中文改写句：仍有“得／的”错误。
- 较长中文句：内容完整。
- 英文句：初稿漏掉的 `Please` 在复核中恢复。
- 混说句：初稿的“标签”在复核中恢复为 `button`。
- stop/flush、两句分段与静音不产生定稿检查通过。

## 未验证或未实现

- 模块化后的独立示例没有真人准确率基准，也未做大量噪声/口音、耗电/发热、峰值内存或长时间会议评测。早期同算法原型通过了麦克风流程，不等于新宿主或所有机型的精度保证。
- 笔测试使用合成事件；模块化后的实体笔完整交互回归仍需用户实际操作。历史硬件发现见 [笔接入](pen-integration.md)。
- iOS、鸿蒙、Windows、macOS、Linux 应用尚未实现；文档是明确的移植方案。
- Gradle 外部宿主消费 AAR、Maven 发布、其他 ABI/系统版本、商店发布兼容性尚未验证。
- GitHub CI 只做纯 Java 与边界检查；真机验证仍由本地脚本执行。
